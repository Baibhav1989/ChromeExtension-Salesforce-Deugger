View Salesforce Apex code coverage by class with advanced metrics, test execution monitoring, and line-level analysis.

Apex Class Coverage Viewer - Your Essential Salesforce Development Tool
Apex Class Coverage Viewer is a powerful Chrome extension for Salesforce developers and QA engineers who need fast, reliable Apex code coverage insights directly in the browser.

🎯 KEY FEATURES
✓ Real-Time Coverage Analysis

View Apex classes with instant coverage metrics
See covered and uncovered lines per class
Track overall organizational coverage in one place
✓ Detailed Metrics Dashboard

Class-wise coverage breakdown
Namespace filtering to exclude managed package classes
Aggregate summary for classes, covered lines, uncovered lines, and overall coverage
✓ Method-Wise Coverage Mapping

Toggle method-wise mode to map Apex methods to test methods
Click any class row to load method-level mapping
Quickly understand which tests cover which logic paths
✓ Test Class Execution Monitoring (NEW)

Select and execute test classes directly from the extension
Live status tracking (Queued, Running, Completed, Failed, Aborted)
Auto-refresh coverage after successful execution
Dedicated execution result section with failed methods and error details
✓ Class Coverage Code Viewer (NEW)

View button for each class row
Opens a VS Code-style dark modal viewer
Line-level display with fixed line numbers
Covered lines highlighted in green, uncovered in red
Smooth vertical/horizontal scrolling for large classes
✓ Advanced Table Interaction (NEW)

Sort by each class table column (ascending/descending)
Real-time search for class names
Works seamlessly with package exclusion and sorting together
✓ CSV Export

Export visible coverage data to CSV
Timestamp-based filename generation for tracking history
Useful for reporting, audits, and compliance documentation
✓ Smart Session Management

Import session from logged-in Salesforce tabs
Supports production, sandbox, and Lightning domains
Local storage for convenience and faster re-use
🔐 SECURITY & PRIVACY
Credentials are stored locally in your browser only
No external server dependency for data processing
No third-party analytics/data collection
Uses official Salesforce Tooling API endpoints
💼 PERFECT FOR
Salesforce developers validating code quality
QA engineers tracking test completeness
Teams managing release readiness and coverage goals
Audit/compliance workflows requiring exportable evidence
⚙️ REQUIREMENTS
Active Salesforce org (production or sandbox)
Valid session/OAuth token with API access
Salesforce API version 50.0+
📝 HOW TO GET STARTED
Click the extension icon
Load/import your Salesforce session
Click Load Coverage
Analyze, sort, filter, execute tests, and inspect line-level coverage
Export CSV when needed
